Accessibility statement for the HMCTS API Marketplace

This statement applies to the HMCTS API Marketplace. It does not cover the AMp API catalogue, which is a separate service with its own accessibility statement.

This service is run by HMCTS Digital and Technology Solutions. We want as many people as possible to be able to use it. That means you should be able to:

  • change colours, contrast levels and fonts
  • zoom in up to 400% without the text spilling off the screen
  • navigate the whole service using just a keyboard
  • navigate the whole service using speech recognition software
  • listen to the service using a screen reader

We have also tried to make the language as plain as possible, which is not always easy for a service about APIs.

Feedback and contact information

If you need information on this service in a different format like accessible PDF, large print, easy read, audio recording or braille, or you find any accessibility problem not listed on this page, contact the marketplace team.

We’ll consider your request and get back to you.

Enforcement procedure

The Equality and Human Rights Commission is responsible for enforcing the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018. If you are not happy with how we respond to your complaint, contact the Equality Advisory and Support Service, or the Equality Commission for Northern Ireland if you live in Northern Ireland.
