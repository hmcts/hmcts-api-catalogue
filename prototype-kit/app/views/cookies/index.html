Cookies

This service does not set any cookies.

There is no sign-in, no analytics, no tag manager and no third-party embed, so there is nothing to consent to and no cookie banner.

What we do store in your browser

Multi-step forms need to remember your answers between one page and the next so you can review them before submitting. We keep those answers in your browser’s session storage.

{{ govukTable({ caption: "Data stored in your browser", captionClasses: "govuk-table__caption--m", firstCellIsHeader: true, head: [ { text: "Name" }, { text: "Purpose" }, { text: "Expires" } ], rows: [ [ { text: "journey:*" }, { text: "Your answers to a multi-step form, so the check-answers page can show them back to you" }, { text: "When you close the browser tab" } ] ] }) }}

This data stays in your browser. It is never sent to us, never stored on a server, and is discarded as soon as you close the tab. Because it is strictly necessary for a form you have asked to use, the law requires us to tell you about it but not to ask your permission.

Turning it off

You can clear session storage or block it in your browser settings. Forms will still work, but each step will forget what you typed on the previous one, and the check-answers page will show your answers as “Not provided”.
