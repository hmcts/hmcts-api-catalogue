Getting started with our APIs

Learn about what APIs we offer and how you can connect to them. These steps will get your team building.

Overview

If you are building justice sector software and need to integrate with HMCTS APIs, this guide is for you.

Whether you are a product owner, delivery lead, architect, software developer or business analyst, you will have a part to play in this process.

{{ govukInsetText({ html: 'If you own an API and want to list it on the marketplace, read the producer standards instead.' }) }}

Steps to get connected

1. Learn about our APIs

Before designing your software, read the onboarding guide, browse the API catalogue, and check the consumer guidance for rate limits and error handling. Review the data governance standards for the data classification and legal obligations that apply. All APIs use OAuth 2.0 with JWT bearer tokens.

2. Create a developer account

Create a developer account on the marketplace and tell us which APIs you are interested in. You will be able to manage your access requests, track approvals, and get issued sandbox and production credentials once approved.

3. Confirm your use case

For all APIs, confirm you have a valid use case and then submit your request to Data Access Panel (DAP), this can be done once you have logged into the developer account created in Step 2. You need to do this step and get approval before you get access to the APIs.

4. Design and build your software

Refer to the API documentation in the catalogue as you build, and read building justice sector software for the design constraints that apply in court and tribunal settings.

5. Test your software

Use the sandbox environment to develop and test your integration. Never test against production. Sandbox credentials are issued once your access request is approved.

6. Get your access approved

Submit an access request describing your use case, expected call volume and environment. The API owner reviews requests and will respond to your requests.

7. Put your software live

Once your access request is approved and you have confirmed your integration works in sandbox, request production credentials and go live.

If you have any issues, either during development or once your software is live, you can contact the marketplace team.

Read the consumer guidance for detailed information on using APIs responsibly, or the data governance standards for your legal obligations.
