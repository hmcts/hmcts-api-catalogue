What the developer community is for

An open forum where consumers, producers and technical specialists can ask and answer questions about integrating with HMCTS APIs and services. It is intended for the questions that are useful to more than one team — the answers stay searchable rather than living in one inbox.

Categories

API platform
General questions about the marketplace platform, including authentication, rate limiting, logging and monitoring.
Data governance
Questions about data classification, data sharing agreements, and the data governance standards.
Per-API discussion
Each published API gets its own category — for example Crime Prosecution Case Details, or Court Listings and Scheduling — for questions specific to that API and its data.

The kinds of questions it answers

From what teams currently ask the marketplace team directly:

  • generating a valid JWT bearer token, and what to do when it fails
  • redirect URI options for internal service accounts
  • moving from sandbox to production access
  • sandbox returning 429 after a handful of calls
  • which classification applies to a combined case and hearing response

Several of these are covered in consumer guidance — the error handling and rate limit sections in particular.
